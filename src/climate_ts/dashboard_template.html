What the design protects against

Training uses the preceding 600 months at each origin. All lag features and scaling use only available history. Recursive forecasts use earlier predictions within the forecast block. Full-history decomposition is descriptive and never feeds backtest features.

How to read the results

MAE and RMSE are in °C. MASE scales errors by historical seasonal differences. MAPE is avoided because anomalies cross zero. Interval radii come from a separate calibration period, but temporal dependence and only ten calibration errors per horizon prevent an exact coverage guarantee.

Annual trend estimates use HAC standard errors. Break-point searches are exploratory, not causal attribution. Both sources' bootstrap intervals for improvement include zero. Historical gains do not establish decisive model superiority.

Reproduce the complete project

Run the notebook from its first cell, or run python -m climate_ts.cli run from the project folder. The offline dashboard embeds all required data and plotting code. Exported figures and a visualization gallery accompany it.
